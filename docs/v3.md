# Deliberation Process Design Tool Redesign

Update the the app with the following.

## Goals

Remember the last question asks the user to rank their goals. Each selection represents a deliberation principle:

- I want more people to participate (inclusion)
- I want a wide variety of ideas (plurality)
- I want a wide variety of people (equality)
- I want deeper discussions (reflection)
- I want honest ideas (authenticity)

Recommendations are displayed based on this selected order.

## Recommendations

There are 4 variables that will inform the recommendations that get displayed:

- size: small, medium, large (set on question 1)
- level: inform, consult, etc. (set on question 2)
- mode: online, offline, or both (set on question 3)
- criteria: self-selection, sortition (set on question 4)

The other 4 questions just determine the order of the recommendations (and which recommendations get displayed). Don't worry about this yet. This will be used in a future version of the app.

Recommendations have:

- name: title of the recommendation
- description: description of why and how to implement the
- stage: each recommendation is related to at least one stage
- pros: description of the positive consequence of implementing the recommendation
- cons: description of the negative consequence of implementing the recommendation

Recommendations are tracked in a csv file with columns: size, level, mode, criteria, name, description, stage, pro, cons. Each row represents one possible selection made by the user. Create this file and stor the recommendation below.
